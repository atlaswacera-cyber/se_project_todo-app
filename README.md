# Simple Todo App

This is a simple and interactive to-do list application that lets users create, view, complete, and delete tasks. It helps organize daily tasks in a clean and easy-to-use interface.

## Functionality

The Simple Todo App allows users to:

- add a new to-do item
- optionally assign a due date to a task
- mark tasks as completed using a checkbox
- delete tasks from the list
- validate form inputs before submitting
- reset the form after a successful submission

The app also starts with a few default to-do items already displayed on the page.

## Technology

This project was built using:

- HTML for the page structure
- CSS for styling and responsive design
- JavaScript for interactivity and dynamic rendering
- ES6 modules for organizing code into separate files
- classes (`Todo` and `FormValidator`) to separate responsibilities and keep the code organized
- UUID for generating unique IDs for new to-do items
